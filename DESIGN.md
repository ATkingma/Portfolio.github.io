# Design Direction

The website must feel:

- professional
- premium
- technical
- mature
- restrained
- human-designed

Avoid:

- AI-looking gradients
- excessive rounded cards
- excessive glassmorphism
- generic hero sections
- huge meaningless headings
- excessive animations
- generic dashboard/card layouts
- purple/blue AI aesthetics
- decorative elements without purpose

Visual references:

- AFAS
- Linear
- Stripe
- Vercel

The design should prioritize:

- typography
- spacing
- hierarchy
- composition
- consistency
- meaningful content
- subtle interactions

## Candidate directions explored (see claude-ideas/)

- A — Mono Dark Bento (Vercel/Linear: black, lime accent, bento stats, monospace labels)
- B — Soft Light SaaS (Stripe/Framer: white, indigo accent, soft shadows)
- C — Warm Editorial (current site's refined direction: bronze accent, magazine grid)
- D — Split Sidebar (fixed profile sidebar + scrollable content, teal accent, docs feel)
- E — Ultra Minimal (white, no accent color, pure type + rules)

Pick one direction (or merge specific elements) and apply it consistently across every page — do not mix palettes/radii/type scales between sections.
